#ToDo List
##Project Overview
The ToDo List Application is a simple Python-based console application developed as a first-semester VITyarthi project.
 It helps users manage their daily tasks through a menu-driven interface.
 Users can add tasks, view their tasks, mark tasks as completed and delete tasks.

 ## Problem Statement
Managing daily tasks using paper notes or memory can make it difficult to keep track of unfinished work. This project provides a simple
console-based solution for organizing and managing tasks in one place.

##Objective
Create a simple and easy-to-use task management application.
Allow users to add new tasks.
Display the current list of tasks.
Mask tasks as completed.
Delete tasks that are no longer required.

##Features
Add a new task.
View all tasks.
Mark a task as completed.
Delete a task.
Menu-driven console interface.
Basic input validation 
Simple and lightweight implementation.

##Limitations
1. Tasks are stored only during the current program session.
2. Tasks are not permanently saved to a database or file.
3. The application currently uses a console interface.
4. There are no user accounts or online synchronisation features.
