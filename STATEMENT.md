# To-Do List Application

## Project Statement

The **To-Do List Application** is a simple Python-based project developed to help users manage their daily tasks efficiently.

The application provides a menu-driven interface through which users can:

* Add new tasks
* View all tasks
* Mark tasks as completed
* Delete tasks
* Exit the application

Each task is stored with its task description and completion status. The program uses Python concepts such as **lists, dictionaries, loops, conditional statements, user input, and functions of list operations**.

## Objective

The main objective of this project is to develop a simple and user-friendly task management system while applying basic Python programming concepts learned during the first semester.

## Technologies Used

* Python
* Visual Studio Code
* GitHub

## Features

1. **Add Task** – Allows the user to add a new task.
2. **View Tasks** – Displays all available tasks along with their status.
3. **Mark as Completed** – Changes a task's status from pending to completed.
4. **Delete Task** – Removes a selected task from the list.
5. **Exit** – Closes the application.

## Conclusion

This project demonstrates the practical use of basic Python programming concepts to create a simple and useful task management application.
